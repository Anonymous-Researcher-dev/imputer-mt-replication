## 🔬 What this is

We ask **which metamorphic properties expose implementation faults in data imputers**, and which of them are necessary or redundant. Instead of hand-written faults, we generate mutants **automatically from the real source code** of scikit-learn 1.6.1 and of a SoftImpute solver.

| 🧩 | |
|---|---|
| **Subjects** | `SimpleImputer`, `KNNImputer` (with `nan_euclidean_distances`), `IterativeImputer`, and a SoftImpute solver (secondary) |
| **Mutants** | **864**, generated by an AST engine with a 17-category operator catalogue |
| **Properties** | **17** invariants, an analytic oracle, a symmetry, a robustness check and metamorphic relations |
| **Conditions** | **120** randomized: 12 data sources (6 real, 6 synthetic), MCAR / MAR / MNAR, random rate and size, structural stressors |
| **Credit rule** | ✅ A property kills a mutant only in conditions where the **unmutated** implementation satisfies it |

### 📊 Headline numbers

| | |
|---|---|
| Mutation score (property-based) | **60.1 %** (149 of 248 analysed mutants) |
| `IterativeImputer` | **24.1 %**: the hardest component |
| Baseline suite of 7 properties | **37.1 %** |
| Smallest suite preserving every kill | **11** properties |

## 🚀 Reproducing the results

```
 conditions ──▶ reference gate ──▶ mutants ──▶ supervised execution ──▶ classification ──▶ RQ1 · RQ2 · RQ3 · RQ4
  (120, seeded)   (unmutated)      (864, AST)    (hard timeouts)         (6 classes)         (CSV + findings)
```

**1️⃣ Install** (Python 3.12):

```bash
pip install -r requirements.txt
```

**2️⃣ Cache California Housing once.** The experiment loads it with `download_if_missing=False`.

> ⚠️ If it is not cached, it is **silently skipped** and the run would use eleven sources instead of twelve.

```bash
python -c "from sklearn.datasets import fetch_california_housing; fetch_california_housing()"
```

**3️⃣ Run the notebook.** Keep `PROFILE = "full"` for the paper run (`"quick"` checks the pipeline in minutes) and run all cells. The master seed is `20261029`; conditions, property parameters and bootstrap resamples all derive from it.

**4️⃣ Collect the outputs** in `results_icst2027_<profile>/`. An interrupted run can be resumed (`RESUME = True`).

⏱️ The full run executes thousands of (mutant, subject) tasks in supervised worker processes (up to 16 in the reported run). Faulty library code can hang inside native routines, so every task has a hard wall-clock limit. Wall-clock time depends on the number of cores.

- 🏷️ The statement-level fault-family labels are **keyword heuristics**, and equivalent mutants are **not** decided automatically (see the notebook's last section and the paper's threats to validity).
